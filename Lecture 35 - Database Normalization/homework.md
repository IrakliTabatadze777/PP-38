# 🏠 საშინაო დავალება — მონაცემთა ბაზის ნორმალიზაცია და JOIN ოპერატორები

## მიზანი

ამ დავალების მიზანია:

- არანორმალიზებული მონაცემების ნორმალიზება;
- მონაცემების რამდენიმე დაკავშირებულ ცხრილად დაყოფა;
- `PRIMARY KEY` და `FOREIGN KEY` გამოყენება;
- სხვადასხვა ცხრილიდან ინფორმაციის მიღება `JOIN` ოპერატორების გამოყენებით;
- `JOIN`-ებთან ერთად მონაცემების გაფილტვრა `WHERE` პირობის გამოყენებით.

# ნაწილი 1 — ნორმალიზაცია

შექმენით ნორმალიზებული მონაცემთა ბაზა.

თქვენ თავად გადაწყვიტეთ:

- რამდენი ცხრილი იქნება;
- რომელი ინფორმაცია რომელ ცხრილში მოხვდება;
- რომელი ველები იქნება `PRIMARY KEY`;
- სად გამოიყენებთ `FOREIGN KEY`;
- როგორ დაუკავშირდება ცხრილები ერთმანეთს.

# ნაწილი 2 — JOIN მოთხოვნები

თქვენს მიერ შექმნილი ცხრილების გამოყენებით დაწერეთ შემდეგი მოთხოვნები.

---

# მნიშვნელოვანი მითითება — JOIN და ფილტრაცია

როდესაც რამდენიმე ცხრილს აერთიანებთ `JOIN`-ის საშუალებით, გაფილტვრა ხდება ჩვეულებრივად `WHERE` პირობის გამოყენებით.

მაგალითად:

```sql
SELECT 
    customers.name,
    products.product_name
FROM customers
JOIN orders 
    ON customers.id = orders.customer_id
JOIN order_items
    ON orders.id = order_items.order_id
JOIN products
    ON products.id = order_items.product_id
WHERE products.category = 'Electronics';
```

ამ შემთხვევაში:

1. ჯერ ხდება ცხრილების გაერთიანება `JOIN`-ით;
2. შემდეგ მიღებული შედეგებიდან ირჩევა მხოლოდ ის ჩანაწერები, რომლებიც აკმაყოფილებს `WHERE` პირობას.

ასევე შესაძლებელია გაფილტვრა ნებისმიერი დაკავშირებული ცხრილის ველის მიხედვით:

მაგალითად:

```sql
WHERE customers.name = 'გიორგი ბერიძე'
```

ან:

```sql
WHERE orders.order_date = '2026-06-05'
```

ან:

```sql
WHERE products.price > 500
```
