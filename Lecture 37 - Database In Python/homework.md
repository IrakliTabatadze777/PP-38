# SQLAlchemy ORM


---

## დავალება

შექმენით PostgreSQL მონაცემთა ბაზაში **`books`** ცხრილი SQLAlchemy ORM-ის გამოყენებით.

ცხრილს უნდა ჰქონდეს შემდეგი ველები:

| ველი | ტიპი |
|------|------|
| id | Integer (Primary Key) |
| title | String |
| author | String |
| publish_year | Integer |

---

## შესასრულებელი ნაბიჯები

### 1. შექმენით Engine

დააკავშირეთ თქვენი პროგრამა PostgreSQL მონაცემთა ბაზასთან `create_engine()` ფუნქციის გამოყენებით.

---

### 2. შექმენით Base კლასი

გამოიყენეთ `DeclarativeBase`.

---

### 3. შექმენით `Book` Model

აღწერეთ `books` ცხრილი ORM კლასის საშუალებით.

---

### 4. შექმენით ცხრილი

გამოიყენეთ:

```python
Base.metadata.create_all(engine)
```

---

### 5. შექმენით Session

გამოიყენეთ `sessionmaker()` და შექმენით `Session`.

---

### 6. დაამატეთ მონაცემები

ბაზაში შეინახეთ მინიმუმ **5 წიგნი**.

---

### 7. SELECT ოპერაციები

შეასრულეთ შემდეგი მოთხოვნები:

- გამოიტანეთ ყველა წიგნი.
- გამოიტანეთ მხოლოდ ერთი წიგნი `id`-ის მიხედვით.
- გამოიტანეთ ყველა წიგნი, რომლის `publish_year` მეტია **2015-ზე**.

---

### 8. UPDATE

იპოვეთ ერთ-ერთი წიგნი `id`-ის მიხედვით და შეცვალეთ მისი ავტორის სახელი.

ცვლილება აუცილებლად შეინახეთ `commit()`-ით.

---

### 9. DELETE

წაშალეთ ერთ-ერთი წიგნი `id`-ის მიხედვით.

---

### 10. Session

პროგრამის ბოლოს დახურეთ Session.
