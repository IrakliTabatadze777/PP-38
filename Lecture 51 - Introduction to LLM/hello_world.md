Here is the simplest "Hello, World!" program in Python:

```python
print("Hello, World!")
```

### How to run it:

1. **Install Python**: Make sure Python is installed on your computer (from [python.org](https://www.python.org/)).
2. **Save the code**: Open a text editor (like VS Code, Notepad, or TextEdit), paste the code above, and save the file as `hello.py`.
3. **Run the file**: Open your Terminal (Mac/Linux) or Command Prompt (Windows), navigate to where you saved the file, and run:

   ```bash
   python hello.py
   ```
   *(Note: On Mac/Linux, you might need to type `python3 hello.py` instead).*
