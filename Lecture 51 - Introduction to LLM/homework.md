# LLM API

## ამოცანა 1. ჩატბოტი

დაწერეთ Python პროგრამა, რომელიც რეალიზებს მარტივ მრავალმხრივ ჩატს Gemini API-ის გამოყენებით.

### მოთხოვნები:
- პროგრამა უნდა კითხულობდეს `GEMINI_API_KEY`-ს გარემოს ცვლადიდან ან `.env` ფაილიდან.
- უნდა ჰქონდეს **system instruction** (მაგალითად: „შენ ხარ მოკლე, მეგობრული და გასაგები ასისტენტი“).
- მომხმარებელთან უნდა აწარმოოს მინიმუმ **3–4 ეტაპიანი** საუბარი.
- ყოველი ახალი მომხმარებლის შეტყობინებისას **მთელი საუბრის ისტორია** უნდა გაიგზავნოს ხელახლა (`UserContent` + `ModelContent`).
- საუბრის ბოლოს უნდა დაიბეჭდოს გამოყენებული ტოკენების სტატისტიკა (`usage_metadata`: prompt, candidates, thoughts, total).

---

## ამოცანა 2. System Instruction-ის გავლენა

### მოთხოვნები:
- აირჩიეთ **ერთი და იგივე** მომხმარებლის კითხვა (მაგალითად: „შემიძლია თუ არა თანხის დაბრუნება, თუ აზრი შევიცვალე?“ ან სხვა თქვენთვის საინტერესო კითხვა).
- გაუშვით მოდელი **სამი განსხვავებული** system instruction-ით:
  1. **ფორმალური** — პროფესიონალი, სიფრთხილით და ზუსტად მომუშავე ასისტენტი.
  2. **მეგობრული / არაფორმალური** — თბილი, მარტივი ენით მომუშავე ასისტენტი.
  3. **სარკასტული ან იუმორისტული** — მსუბუქი, ირონიული ტონით მომუშავე ასისტენტი.

## ამოცანა 3. შეცდომების დამუშავება (Error Handling)

დაწერეთ პროგრამა, რომელიც **განზრახ** იწვევს და სწორად ამუშავებს შემდეგ შეცდომებს. თითოეული შეცდომისთვის უნდა დაიბეჭდოს გასაგები, სტუდენტისთვის მეგობრული შეტყობინება.

### დასამუშავებელი შეცდომები:

| შეცდომა                     | რას წარმოადგენს                                                       | რა უნდა მოხდეს კოდში                                                                                             |
| --------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Missing API Key**         | `GEMINI_API_KEY` საერთოდ არ არის მითითებული გარემოში ან `.env` ფაილში | პროგრამა არ უნდა ჩავარდეს. უნდა გამოჩნდეს მკაფიო შეტყობინება, თუ როგორ უნდა დაყენდეს გასაღები.                   |
| **Invalid API Key**         | გადაცემულია არასწორი / ფეიკ API key                                   | უნდა დაიჭიროს ავტორიზაციის შეცდომა და აუხსნას მომხმარებელს, რომ პრობლემა credentials-შია და არა კოდის სინტაქსში. |
| **არასწორი მოდელის სახელი** | გამოყენებულია არარსებული ან მოძველებული მოდელის იდენტიფიკატორი        | უნდა დაიჭიროს შესაბამისი შეცდომა და უთხრას მომხმარებელს, რომ მოდელის სახელი არასწორია.                           |
| **ზოგადი API შეცდომა**      | ნებისმიერი სხვა მოულოდნელი შეცდომა API-დან                            | უნდა დაიჭიროს ზოგადი გამონაკლისი და დაბეჭდოს შეცდომის ტიპი + მოკლე აღწერა.                                       |

### შეცდომების გამოწვევის ნიმუშები

ქვემოთ მოცემულია მაგალითები, თუ როგორ შეგიძლიათ **განზრახ** გამოიწვიოთ თითოეული შეცდომა ტესტირებისთვის:

#### 1. Missing API Key
```python
from google import genai

try:
    client = genai.Client(api_key=None)  # ან საერთოდ არ გადავცეთ api_key
    client.models.generate_content(
        model="gemini-2.0-flash",
        contents="Hello"
    )
except Exception as e:
    print(type(e).__name__)
    print(e)
```

#### 2. Invalid API Key
```python
from google import genai
from google.genai import errors

client = genai.Client(api_key="this-is-not-a-real-key")

try:
    client.models.generate_content(
        model="gemini-3.6-flash",
        contents="Hello"
    )
except errors.ClientError as e:
    print(f"status: {e.code}")
    print(e)
```

#### 3. არასწორი მოდელის სახელი
```python
from google import genai
from google.genai import errors

client = genai.Client()  # სწორი API key-ით

try:
    client.models.generate_content(
        model="gemini-nonexistent-model-123",  # არარსებული მოდელი
        contents="Hello"
    )
except errors.ClientError as e:
    print(f"status: {e.code}")
    print(e)
```

#### 4. ზოგადი API შეცდომა
```python
from google import genai

client = genai.Client()

try:
    # აქ შეგიძლიათ გამოიწვიოთ სხვა მოულოდნელი შეცდომა
    # მაგალითად, არასწორი პარამეტრების გადაცემით ან ქსელის პრობლემის სიმულაციით
    client.models.generate_content(
        model="gemini-3.6-flash",
        contents="Hello",
        config={"invalid_param": True}  # არასწორი კონფიგურაცია
    )
except Exception as e:
    print(type(e).__name__)
    print(e)
```
