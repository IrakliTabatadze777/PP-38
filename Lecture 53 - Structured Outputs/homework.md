# ამოცანა 1 — Token Counting & Context Window

შექმენი Python პროგრამა, რომელიც დაგეხმარება გაიგო, **რამდენ ტოკენს იკავებს კონკრეტული ტექსტი ან conversation history**.

პროგრამამ უნდა გამოიყენოს Gemini-ის `client.models.count_tokens()` მეთოდი.

### მოთხოვნები

პროგრამამ უნდა:

1. მიიღოს ტექსტი, რომლის ტოკენების რაოდენობაც უნდა დაითვალოს.
2. გამოიყენოს:

```python
client.models.count_tokens()
```

3. დაბეჭდოს ტექსტის ტოკენების რაოდენობა.
4. შეამოწმოს მიღებული რაოდენობა:

   * თუ ტოკენების რაოდენობა **0-ის ტოლია**, დაბეჭდოს შესაბამისი შეტყობინება.
   * თუ ტოკენების რაოდენობა **300-ზე მეტია**, დაბეჭდოს გაფრთხილება ან შექმნას შეცდომა.
   * სხვა შემთხვევაში დაბეჭდოს, რომ ტექსტის ზომა დასაშვებ ლიმიტშია.
5. პროგრამა დატესტე **მინიმუმ 3 განსხვავებული ტექსტით**:

   * მოკლე ტექსტი;
   * საშუალო სიგრძის ტექსტი;
   * გრძელი ტექსტი.

### დამატებითი მოთხოვნა

დავალება გააკეთე ისე, რომ ტოკენების დათვლის ლოგიკა ცალკე ფუნქციაში იყოს, მაგალითად:

```python
def count_text_tokens(text):
    ...
```

შემდეგ ეს ფუნქცია გამოიყენე სამივე ტექსტის შესამოწმებლად.

# ამოცანა 2 — History Trimming

შექმენი ფუნქცია:

```python
def trim_history(history: list, max_turns: int):
    ...
```

რომელიც conversation history-ს შეამოკლებს და დატოვებს მხოლოდ ბოლო რამდენიმე **მონაცვლეობას**.



### მოთხოვნები

1. შექმენი ხელოვნური conversation history, რომელიც შეიცავს **მინიმუმ 20 turn-ს**.

2. შექმენი `trim_history()` ფუნქცია.
3. ფუნქციამ უნდა დატოვოს მხოლოდ ბოლო `max_turns` turn.
4. ფუნქცია გამოიყენე მინიმუმ შემდეგი მნიშვნელობებით:

```python
max_turns=4
max_turns=6
max_turns=10
```

5. თითოეული ვარიანტისთვის დაბეჭდე რამდენი შეტყობინება დარჩა history-ში.


6. `client.models.count_tokens()`-ის გამოყენებით დაითვალე:

   * სრული history-ის ტოკენების რაოდენობა;
   * `max_turns=4`-ის შემდეგ დარჩენილი history-ის ტოკენები;
   * `max_turns=6`-ის შემდეგ დარჩენილი history-ის ტოკენები;
   * `max_turns=10`-ის შემდეგ დარჩენილი history-ის ტოკენები.

# ამოცანა 3 — Structured Output

შექმენი პროგრამა, რომელიც Gemini-ისგან მიღებულ პასუხს **წინასწარ განსაზღვრულ სტრუქტურაში** მიიღებს.

### 1. შექმენი `Book` მოდელი

შექმენი Pydantic მოდელი შემდეგი ველებით:

```python
class Book(BaseModel):
    title: str
    author: str
    year: int
    genres: list[str]
```

ველების მნიშვნელობები უნდა იყოს:

| ველი     | ტიპი        | აღწერა         |
| -------- | ----------- | -------------- |
| `title`  | `str`       | წიგნის სათაური |
| `author` | `str`       | ავტორი         |
| `year`   | `int`       | გამოცემის წელი |
| `genres` | `list[str]` | წიგნის ჟანრები |

### 2. გაუგზავნე მოთხოვნა მოდელს
სთხოვე გირჩიოს რომელიმე ჟანრის წიგნი წასაკითხად

### 3. დაამუშავე მიღებული პასუხი

მიიღე მოდელის პასუხი და შეამოწმე, რომ ის შეესაბამება `Book` მოდელს.

საბოლოოდ პროგრამამ უნდა შეძლოს ისეთი სტრუქტურის მიღება, როგორიცაა:

```json
{
    "title": "The Hound of the Baskervilles",
    "author": "Arthur Conan Doyle",
    "year": 1902,
    "genres": ["Mystery", "Detective", "Fiction"]
}
```

### 4. დაბეჭდე მონაცემები

პროგრამამ ცალ-ცალკე დაბეჭდოს:

```text
Title: ...
Author: ...
Year: ...
Genres: ...
```
