# ამოცანა 1. მექანიკური RAG სრული ციკლით
>დავალების შესასრულებლად გამოიყენეთ [company_handbook.md](company_handbook.md)

1. დაწერეთ ფუნქცია, რომელიც იღებს გრძელ ტექსტს და ყოფს მას ფიქსირებული ზომის ნაწილებად (chunks).  
   - თითოეული ნაწილი უნდა იყოს დაახლოებით 400–600 სიმბოლო.  
   - მეზობელ ნაწილებს შორის აუცილებლად უნდააკეთეთ გადაფარვა (overlap) 80–150 სიმბოლოთი, რომ კონტექსტი არ დაიკარგოს.  

2. ყველა chunk შეინახეთ ვექტორულ მონაცემთა ბაზაში.  
   - თითოეული ნაწილისთვის უნდააგენერირეთ embedding.  
   - მინიშნება: გამოიყენეთ PostgreSQL + pgvector და შეინახეთ როგორც vector ტიპი.
   - შეინახეთ metadata თითოეული ჩანკისთვის(chunk)

3. მიიღეთ მომხმარებლისგან input.
   - გამოიყენეთ input მომხმარებლის ტექსტის მისაღებად
   - აქციეთ ის ემბედინგათ(embedding), იმავე მოდელის გამოყენებით, რომელიც გამოიყენეთ დოკუმენტებისთვის

4. ვექტორულ ბაზაში იპოვეთ ყველაზე ახლოს მდგომი N ნაწილი.  
   - გამოიყენეთ კოსინუსური მანძილი (<=> ოპერატორი).  
   - დაალაგეთ მზარდი მანძილის მიხედვით და აიღეთ მხოლოდ top-k (რეკომენდებულია k=4 ან 5).

5. ნაპოვნი კონტექსტის საფუძველზე ააგეთ prompt.  
   - prompt-ში მკაცრად მიუთითეთ: „პასუხი გაეცი მხოლოდ მოცემულ კონტექსტზე დაყრდნობით. თუ ინფორმაცია არ არის — თქვი, რომ საკმარისი ინფორმაცია არ გაქვს“.  
   - კონტექსტში თითოეული ნაწილი წარმოადგინეთ წყაროსა და ინდექსის მითითებით.

6. LLM-ს გაუგზავნეთ მზა prompt და დაბეჭდეთ მხოლოდ პასუხის ტექსტი.

---

**ამოცანა 2. LangChain-ის გამოყენებით RAG სრული ციკლით (ინგესტია + retrieval chain)**

1. იგივე ტექსტი დაყავით ნაწილებად overlap-ით (იგივე წესებით, რაც ამოცანა 1-ში) და აქციეთ Document ობიექტებად იგივე მეტამონაცემებით.

2. Document-ები შეინახეთ LangChain-ის ვექტორულ store-ში (PGVector).  
   - მინიშნება: გამოიყენეთ GoogleGenerativeAIEmbeddings და მიუთითეთ embedding_length.

3. შექმენით retriever:  
   - vector_store.as_retriever(search_kwargs={"k": 5})

4. ააგეთ სრული retrieval chain:  
   - გამოიყენეთ create_stuff_documents_chain და create_retrieval_chain.  
   - prompt template ჩამოტვირთეთ LangSmith-იდან (retrieval-qa-chat ტიპის).  
   - მინიშნება: chain-ს გადაეცით {"input": "კითხვა"} და პასუხი აიღეთ result["answer"]-დან.

5. chain-ს გადაეცით მომხმარებლის კითხვა და დაბეჭდეთ მხოლოდ საბოლოო პასუხი.
