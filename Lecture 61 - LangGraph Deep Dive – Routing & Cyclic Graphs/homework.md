### ამოცანა 1 — Conditional Edges


შექმენით LangGraph, რომელიც მომხმარებლის მოთხოვნის ტიპის მიხედვით ირჩევს ორ სხვადასხვა გზას:

| თუ `user_request`-ში არის... | მაშინ გაეშვას კვანძი... | რას აკეთებს კვანძი |
|-----------------------------|------------------------|---------------------|
| სიტყვა **"შეჯამება"** ან **"summary"** | `summarize` | LLM-ს სთხოვს მოცემული ტექსტის მოკლე შეჯამებას (2–3 წინადადებით) |
| სხვა ნებისმიერი მოთხოვნა | `translate` | LLM-ს სთხოვს იმავე ტექსტის თარგმანს **ინგლისურად** |

**ტექნიკური მოთხოვნები**

1. **State**  
   გამოიყენეთ `TypedDict` სახელად მაგალითად `TextState` და გქონდეთ მინიმუმ ეს ველები:
   ```python
   class TextState(TypedDict):
       user_request: str
       text: str
       response: str
   ```

2. **ორი კვანძი**
   - `summarize_node(state)` — იღებს `state["text"]`-ს, აგზავნის LLM-ს და აბრუნებს `{"response": "..."}`.
   - `translate_node(state)` — იგივე, მაგრამ თარგმნის ინგლისურად.

3. **როუტინგი**
   - დაწერეთ ფუნქცია `route_by_request(state)`, რომელიც ამოწმებს `state["user_request"]`-ს.
   - თუ შეიცავს `"შეჯამება"` ან `"summary"` → დააბრუნოს `"summarize"`.
   - სხვა შემთხვევაში → დააბრუნოს `"translate"`.

4. **გრაფის აგება**
   - `START`-დან გამოიყენეთ `add_conditional_edges` და დააკავშირეთ ორ კვანძთან.
   - ორივე კვანძიდან პირდაპირ `END`-ზე გადადით.

5. **გაუშვით გრაფი ორი სხვადასხვა შემთხვევით და დაბეჭდეთ შედეგები:**
   - ერთი შეჯამების მოთხოვნით
   - ერთი თარგმანის მოთხოვნით

### ამოცანა 2 — Tools + Cycle Graph


შექმენით აგენტი, რომელსაც აქვს ორი ხელსაწყო:

1. `get_book_info(title: str)` — აბრუნებს ფიქტიურ ინფორმაციას წიგნზე (ავტორი, გამოცემის წელი, მოკლე აღწერა).
2. `get_movie_info(title: str)` — აბრუნებს ფიქტიურ ინფორმაციას ფილმზე (რეჟისორი, წელი, ჟანრი).

აგენტი უნდა მუშაობდეს ციკლით:
- მოდელი იძახებს ხელსაწყო(ებ)ს საჭიროებისამებრ,
- ხელსაწყოების შედეგები უბრუნდება მოდელს,
- მოდელი საბოლოო პასუხს აბრუნებს.

**ტექნიკური მოთხოვნები**

1. **State**
   ```python
   class AssistantState(TypedDict):
       messages: Annotated[list[BaseMessage], add_messages]
   ```

2. **ხელსაწყოები**
   - გამოიყენეთ `@tool` დეკორატორი ორივე ფუნქციაზე.
   - ფიქტიური მონაცემები შეინახეთ dictionary-ში.

3. **კვანძები**
   - `call_model` — მოდელი დააკავშირეთ ხელსაწყოებთან (`bind_tools`) და გამოიძახეთ.
   - `call_tools` — წაიკითხეთ `tool_calls`, გამოიძახეთ შესაბამისი ფუნქციები და დააბრუნეთ `ToolMessage`-ები.

4. **პირობითი edge**
   - `should_continue` ფუნქციით გადაწყვიტეთ: თუ არის `tool_calls` → `"call_tools"`, წინააღმდეგ შემთხვევაში → `END`.

5. **ციკლი**
   - `call_tools` → ისევ `call_model`.

6. **გაუშვით გრაფი მინიმუმ ერთი ასეთი კითხვით:**  
   *„მითხარი რამე წიგნზე '1984' და ფილმზე 'Inception'"*  
   და დაბეჭდეთ ყველა შეტყობინება (`HumanMessage`, `AIMessage`, `ToolMessage`).
